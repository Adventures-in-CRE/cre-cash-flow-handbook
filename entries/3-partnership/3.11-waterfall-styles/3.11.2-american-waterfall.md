## Purpose

In an American waterfall the sponsor can earn promote before the limited
partner has its capital back. Operating distributions and capital event
distributions run on different orders, which front-loads cash to the sponsor.
Sponsors prefer it, and it is the reason clawback provisions exist.

## Inputs

Distributable Cash (3.10.1) and each distribution tier: Return of Capital
(3.10.2), Preferred Return (3.10.3), GP Catch-Up (3.10.4), Promote Tier
(3.10.5), Residual Split (3.10.6).

## Output

A distribution per partner per period.

## Method

Run operating distributions through the preferred return and promote tiers
without first returning capital. Run capital event distributions through return
of capital first. Reconcile at the end of the investment.

## Rules

1. Operating distributions follow Preferred Return (3.10.3), then GP Catch-Up
   (3.10.4), then Promote Tier (3.10.5). Return of Capital (3.10.2) is not
   required first.
2. Capital event distributions return capital (3.10.2) before promote is paid
   on those proceeds.
3. The entry states the order for each of the two streams separately. A single
   stated order is not an American waterfall.
4. Promote may be paid before the LP's final return is known, so LP Clawback
   (3.12.1) is required rather than optional.
5. Within each stream, tiers apply lowest hurdle first, as under the European
   style (3.11.1).
